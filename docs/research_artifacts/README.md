# Research Artifacts

This folder contains dissertation-facing research artifacts for the Stock-Flow Labour-Value Accounting protocol.

Files:

- `SFLV_source_hygiene_audit.csv`: source-hygiene review of the raw deep-research synthesis.
- `SFLV_research_artifact.md`: polished dissertation-facing research note.
- `SFLV_research_artifact_validation.md`: validation record for this inspection/polish pass.

The raw input remains `docs/deep-research-report.md`. It is a synthesis draft and is not treated as final authority. The polished artifact uses it only to improve exposition, organize workflow implications, and identify checks requiring validation.

The polished artifact supports the Stock-Flow Labour-Value Accounting Skill by restating the source hierarchy, account ladder, finance/banking treatment, BEA API concept-first workflow, candidate statuses, and no-construction boundary.

The same schema logic may later support Shiny app framing, but this folder does not create an app.

Not authorized here:

- adjusted Shaikh time series;
- model-input panel variables;
- provider handoffs;
- econometrics;
- GPIM reconstruction;
- theta estimation;
- productive capacity, utilization, or accumulated q construction;
- source-PDF copying;
- long copyrighted quotations.
